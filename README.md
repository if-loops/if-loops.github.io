# if-loops.github.io

Personal site for Stefan Schöpf, served directly by GitHub Pages as a static site — no build step, no Jekyll.

## Structure

- `index.html` — the whole page
- `assets/css/style.css` — all styles
- `assets/js/main.js` — publication row expand/collapse behavior
- `assets/img/` — headshot and company/university logos
- `images/` — favicons

## Editing

Just edit `index.html` (and `assets/css/style.css` / `assets/js/main.js` as needed) and push to `main`. GitHub Pages picks up changes automatically within a minute or two.
